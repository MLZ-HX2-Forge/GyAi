## 快速开始

### 启动服务

1. 打开命令行终端，进入项目目录
2. 运行启动命令：

```bash
python BackEnd/app.py
```

3. 看到以下提示表示服务启动成功：

```
============================================================
GyAI 工业智能助手
============================================================
数据库类型: SQLITE
服务地址: http://127.0.0.1:5000
主页面: http://127.0.0.1:5000/
对话页面: http://127.0.0.1:5000/chat
监控页面: http://127.0.0.1:5000/monitor
============================================================
```

### 访问系统

在浏览器中输入以下地址访问系统：

| 页面 | 地址 | 说明 |
|------|------|------|
| 首页 | http://127.0.0.1:5000/ | 产品介绍与登录入口 |
| 对话页 | http://127.0.0.1:5000/chat | AI智能对话 |
| 监控页 | http://127.0.0.1:5000/monitor | 实时监控识别 |

## 用户认证

### 注册账号

1. 在首页点击「登录 / 注册」按钮
2. 在弹出的对话框中切换到「注册」标签
3. 填写注册信息：
   - **用户名**：3-20个字符，支持字母、数字、下划线
   - **邮箱**：可选，用于找回密码
   - **密码**：至少6个字符
   - **确认密码**：再次输入密码
4. 点击「注册」按钮完成注册

### 登录系统

1. 在首页点击「登录 / 注册」按钮
2. 输入用户名和密码
3. 勾选「记住我」可保持登录状态
4. 点击「登录」按钮

### 游客模式

如果您想先体验系统功能，可以选择游客模式：

1. 在登录对话框底部点击「以游客身份体验」
2. 系统会自动创建临时账号并登录
3. 游客账号的数据会在退出后清除

## 智能对话功能

### 进入对话页面

登录后，点击导航栏的「对话」或直接访问 http://127.0.0.1:5000/chat

### 界面介绍

```
┌─────────────────────────────────────────────────────────────┐
│  侧边栏          │              主对话区域                    │
│  ┌─────────────┐ │  ┌─────────────────────────────────────┐ │
│  │ 新建对话    │ │  │                                     │ │
│  ├─────────────┤ │  │        AI 回复消息区域              │ │
│  │ 对话历史    │ │  │                                     │ │
│  │ - 对话1     │ │  ├─────────────────────────────────────┤ │
│  │ - 对话2     │ │  │                                     │ │
│  │ - 对话3     │ │  │        用户消息区域                 │ │
│  └─────────────┘ │  │                                     │ │
│  ┌─────────────┐ │  ├─────────────────────────────────────┤ │
│  │ 模型选择    │ │  │  [图片] [输入框]        [发送]     │ │
│  │ DeepSeek    │ │  └─────────────────────────────────────┘ │
│  └─────────────┘ │                                         │
└─────────────────────────────────────────────────────────────┘
```

### 发起对话

1. **文字对话**：
   - 在底部输入框输入问题
   - 点击发送按钮或按 Enter 键发送
   - AI 会实时流式输出回答

2. **图片分析**：
   - 点击输入框左侧的图片图标
   - 选择要上传的图片
   - 输入问题（如"请分析这张图片"）
   - 发送后 AI 会分析图片内容

### 切换模型

系统支持多个 AI 模型，您可以根据需求切换：

| 模型 | 特点 | 适用场景 |
|------|------|----------|
| DeepSeek V3.1 | 逻辑推理能力强 | 技术问题、代码分析 |
| Kimi K2 | 长文本理解 | 文档分析、长篇回答 |
| 豆包视觉 | 图片分析 | 图像识别、视觉问答 |

切换方法：在侧边栏底部的模型选择区域点击对应模型

### 管理对话

1. **新建对话**：点击侧边栏顶部的「新建对话」按钮
2. **切换对话**：点击侧边栏中的历史对话项
3. **删除对话**：鼠标悬停在对话项上，点击删除图标
4. **置顶对话**：鼠标悬停在对话项上，点击置顶图标

1. 在右侧控制面板点击「启动监控」按钮
2. 首次使用会请求摄像头权限，请点击「允许」
3. 摄像头启动后画面会显示在左侧区域

### 摄像头设置

| 设置项 | 说明 |
|--------|------|
| 摄像头选择 | 选择要使用的摄像头设备 |
| 分辨率 | 支持 4K、1080p、720p、480p、360p 或自动 |
| 帧率 | 支持 60、30、24、15 FPS 或自动 |
| 镜像翻转 | 开启后画面左右翻转 |

### AI 识别功能

#### 选择识别模式

- **单模型识别**：使用单个模型进行检测
- **多模型同时识别**：同时使用多个模型进行检测

#### 选择检测模型

| 模型 | 检测内容 | 警告条件 |
|------|----------|----------|
| 粉尘检测 | 空气中的粉尘 | 粉尘浓度过高 |
| 火焰检测 | 火焰、火灾 | 检测到火焰 |
| 反光衣检测 | 反光衣穿着情况 | 未检测到反光衣 |
| 口罩检测 | 口罩佩戴情况 | 有人未戴口罩 |
| 安全帽检测 | 安全帽佩戴情况 | 有人未戴安全帽 |
| 摔倒检测 | 人员姿态 | 检测到摔倒 |

#### 识别参数设置

| 参数 | 范围 | 说明 |
|------|------|------|
| 识别置信度 | 0.1 - 0.9 | 置信度阈值，越高越严格 |
| 识别间隔 | 100 - 1000ms | 每次识别的时间间隔 |
| 显示识别框 | 开/关 | 是否在画面上绘制检测框 |
| 显示标签 | 开/关 | 是否显示检测类别标签 |
| 保存检测结果 | 开/关 | 是否将结果保存到数据库 |

#### 开始识别

1. 选择识别模式和模型
2. 调整识别参数（可选）
3. 点击「开始识别」按钮
4. 检测结果会实时显示在画面左侧

### 检测结果显示

#### 实时警告提示

当检测到异常情况时，画面左侧会显示红色警告提示：

```
┌─────────────────────────┐
│ ⚠ 未戴安全帽    95%     │
└─────────────────────────┘
```

- 仅显示警告类型的检测结果
- 最多同时显示 3 条警告
- 4 秒后自动向上渐渐消失

#### 底部警告横幅

当检测到严重警告时，页面底部会显示警告横幅：

```
┌──────────────────────────────────────────────────────────┐
│ ⚠ 警告: 检测到 1 个警告                                  │
│    安全帽检测: 警告：有人未佩戴安全帽！            [×]   │
└──────────────────────────────────────────────────────────┘
```

### 检测历史

#### 查看历史记录

1. 在右侧面板找到「检测历史」区域
2. 点击展开按钮展开历史列表
3. 历史记录会自动加载

#### 筛选历史

- 使用顶部的模型筛选下拉框
- 选择特定模型查看该模型的检测记录

#### 清除历史

点击清除按钮可清空所有检测历史记录

### 截图与录制

#### 截图

1. 点击「截图」按钮
2. 系统会自动下载当前画面截图
3. 文件名格式：`screenshot_时间戳.png`

#### 录制视频

1. 点击「开始录制」按钮
2. 录制过程中会显示录制时长
3. 点击「停止录制」结束录制
4. 视频会自动下载，格式为 WebM

## 常见问题

### Q1: 摄像头无法启动？

**可能原因：**
1. 浏览器未授予摄像头权限
2. 摄像头被其他应用占用
3. 未检测到摄像头设备

**解决方法：**
1. 检查浏览器地址栏是否有权限提示，点击允许
2. 关闭其他使用摄像头的应用
3. 检查摄像头是否正确连接

### Q2: AI 识别没有结果？

**可能原因：**
1. 置信度阈值设置过高
2. 光线条件不佳
3. 目标物体不在画面中

**解决方法：**
1. 降低识别置信度（如 0.3）
2. 改善光线条件
3. 确保目标物体在画面中清晰可见

### Q3: 对话响应很慢？

**可能原因：**
1. 网络连接问题
2. AI 模型服务繁忙
3. 问题过于复杂

**解决方法：**
1. 检查网络连接
2. 稍后重试
3. 将复杂问题拆分为多个简单问题

### Q4: 如何切换数据库？

系统默认使用 SQLite，如需切换到 MySQL：

1. 修改 `BackEnd/config.py` 中的数据库配置
2. 设置 `DATABASE_TYPE = 'mysql'`
3. 配置 MySQL 连接参数
4. 安装 pymysql：`pip install pymysql`
5. 重启服务

### Q5: 如何添加新的检测模型？

1. 将模型文件（.pt 格式）放入 `models/` 目录
2. 在 `BackEnd/routes/detection.py` 的 `MODELS_CONFIG` 中添加配置：

```python
'new_model': {
    'path': 'models/new_model.pt',
    'name': '新模型名称',
    'warning_threshold': 1,
    'count_label_text': '检测数量',
    'warning_text': '警告信息'
}
```

3. 重启服务
