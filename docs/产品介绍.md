## 功能特性

### 1. 智能对话助手

基于大语言模型的智能对话系统，支持多轮对话与上下文理解。

**核心能力：**
- 多模型支持：集成 DeepSeek V3.1、Kimi K2、豆包视觉等多个国内领先大模型
- 流式响应：实时输出回答内容，提升交互体验
- 上下文记忆：支持多轮对话，理解对话历史
- 图片分析：支持上传图片进行视觉分析

**应用场景：**
- 技术问题咨询
- 操作流程指导
- 故障排查建议
- 知识问答服务

### 2. 实时监控识别

基于 YOLO 深度学习模型的实时视频监控与智能识别系统。

**支持模型：**

| 模型 | 功能 | 应用场景 |
|------|------|----------|
| 粉尘检测 | 检测空气中的粉尘浓度 | 环境监测、安全生产 |
| 火焰检测 | 实时识别火焰和火灾 | 消防安全、预警系统 |
| 反光衣检测 | 检测人员是否穿着反光衣 | 安全合规检查 |
| 口罩检测 | 检测人员是否佩戴口罩 | 卫生安全、防疫要求 |
| 安全帽检测 | 检测人员是否佩戴安全帽 | 施工安全、合规检查 |
| 摔倒检测 | 检测人员摔倒/异常姿态 | 人员安全、紧急救援 |

**核心特性：**
- 单模型/多模型同时识别
- 实时检测框绘制
- 警告自动提示
- 检测结果数据库存储
- 历史记录查询与导出

### 3. 设备故障诊断

结合知识库与 AI 分析能力，快速定位设备故障原因。

**诊断流程：**
1. 用户描述故障现象
2. AI 分析可能原因
3. 提供排查步骤建议
4. 给出维修方案参考

### 4. 专业知识库

内置丰富的工业领域专业知识库，覆盖多个专业领域。

**知识领域：**

| 领域 | 内容 |
|------|------|
| 设备维护 | 设备保养、故障诊断、维修方案 |
| 安全生产 | 安全规范、风险评估、应急预案 |
| 工艺优化 | 流程改进、效率提升、成本控制 |
| 质量管理 | 质量标准、检测方案、体系认证 |

## 部署方式

### 方式一：本地部署

```bash
# 1. 克隆项目
git clone https://github.com/your-repo/GyAI.git
cd GyAI

# 2. 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux
# 或 venv\Scripts\activate  # Windows

# 3. 安装依赖
pip install -r BackEnd/requirements.txt

# 4. 启动服务
python BackEnd/app.py
```

### 方式二：Docker 部署

```bash
# 构建镜像
docker build -t gyai:latest .

# 运行容器
docker run -d -p 5000:5000 gyai:latest
```
